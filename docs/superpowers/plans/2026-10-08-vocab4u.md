# 随浪背单词（Vocab4U）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 上线 `vocab4u.suilang.net` —— 7954 张静态词条页 + 免登录的本地 SRS 单词学习器。

**Architecture:** 纯静态站点（Cloudflare Workers 静态资源，无 Worker 脚本）。Python 生成器把「GPT 单词本正文 + ECDICT 音标/释义/分级 + ipa-dict 兜底」合成结构化数据，再产出全部 HTML；前端只有原生 JS/CSS，学习进度存 localStorage，Service Worker 负责离线。

**Tech Stack:** Python 3（生成器，无第三方依赖）、原生 JS/CSS、Cloudflare Workers Static Assets、Web Speech API + 有道发音接口。

## Global Constraints

- 目录 `/Users/nbody/Desktop/suilang.net/vocab4u_web`，Worker 名 `vocab4u-suilang`，域名 `vocab4u.suilang.net`，仓库 `lovehin/vocab4u_web`（私有）。
- 数据授权：词典正文 CC BY-SA 4.0（必须署名 + 相同方式共享），ECDICT / ipa-dict 为 MIT。
- 文档、注释、提交信息一律中文；提交信息要说清改了什么。
- 生成物 `/w/ /list/ /roots/ /guide/ index.html 404.html about.html privacy.html sitemap.xml robots.txt llms.txt manifest.webmanifest sw.js assets/version.js data/words/` 全部 gitignore，不提交。
- `.assetsignore` 里**绝不能写 `*.txt`**；`_headers` 的 CSP 必须放行 `https://suilang.net`（赞赏码）、`https://hm.baidu.com`、`https://dict.youdao.com`（发音）。
- 推送走本机代理：`git -c http.proxy=http://127.0.0.1:7890 push`。
- `_redirects` 开头必须写「不要写 `/xxx → /xxx.html`」的警告注释。

**Interfaces（供后续任务依赖，必须一致）:**
- `load_words() -> list[dict]`，每条：
  ```python
  {
    "word": "abandon",            # 原始词形
    "slug": "abandon",
    "phonetic_us": "ә'bændәn",    # 可能为空串
    "phonetic_uk": "",
    "trans": ["vt. 放弃, 抛弃", "n. 放任"],
    "tags": ["gk","cet4","cet6","ky","toefl","gre"],
    "books": ["gaokao","cet4","cet6","kaoyan"],
    "frq": 2182, "bnc": 2057, "collins": 3,
    "sections": {"词义": "...", "例句": ["..."], ...},   # Task 2 的解析结果
    "sentences": [{"en": "...", "zh": "..."}],
    "story": {"en": "...", "zh": "..."},
    "exchange": "d:abandoned/p:abandoned/...",
    "updated": "2026-10-08"
  }
  ```
- `write_data(words, roots)` 产出 `data/`。

- [ ] 写 `取数据.py`：缺文件时按 URL 下载到 `build/_raw/`（跳过已存在）；解析 JSONL 时按行首 `{"word":` 切分（正文含裸换行，不能逐行 `json.loads`）。
- [ ] 词书切分按 `zk/gk/cet4/cet6/ky/toefl+ielts+gre`，另出 `all`。
- [ ] slug 规则：小写 → 非 `[a-z0-9]` 转 `-` → 折叠 → 去首尾；冲突追加 `-2`。
- [ ] 词书数据分片 `data/words/<book>.<n>.json`，每片 500 词，字段只留学习器需要的：`word/slug/phonetic/trans/sentences/tags/frq/exchange`。
- [ ] `data/roots.json`：611 条词根里筛出≥3 个本站例词的 288 条；每条 `{key, meaning, class, origin, words:[slug...]}`。
- [ ] 测试：`python3 build/test_取数据.py` 断言—去重后 7954 词、词书词数与文档一致（zhongkao 1588 / gaokao 3657 / cet4 3725 / cet6 5138 / kaoyan 4539）、slug 全局唯一、≥95% 的词有音标。

### Task 2: 正文解析器 `build/解析词条.py`

**Files:** Create `build/解析词条.py`、`build/test_解析词条.py`

**Interfaces:**
- `split_sections(content: str) -> dict[str, str]`：键为八个中文小标题；兼容 `### 标题`、`**标题**`、`标题：`、`标题` 单独成行；无标题的整段放到 `"词义"`。
- `split_examples(raw: str) -> list[dict]`：`{'en': str, 'zh': str}`，兼容三种例句排版（`英文 - 中文`、英文换行中文、英文（中文））。
- `split_story(raw: str) -> {'en': str, 'zh': str}`：小故事英文段 + 中文段。

- [ ] 先写测试：从 `build/_raw/gptwords.json` 抽 200 条，断言
      - 八节解析后 例句节非空比例 ≥ 85%
      - `split_examples` 抽 100 条随机例句，`en` 含 ASCII 字母且 `zh` 含中文的比例 ≥ 90%
      - 无一行里英文与中文黏连未分离。
- [ ] 跑测试确认失败（函数还没写）。
- [ ] 实现解析器（正则 + 状态机），跑到测试通过。
- [ ] 抽样人工看 10 条，修正明显错例。
- [ ] `git commit -m "词条正文解析器：八节切分与例句中英分离"`
