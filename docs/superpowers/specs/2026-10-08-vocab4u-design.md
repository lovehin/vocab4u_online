## 一、目标与非目标

### 目标
1. 打开网页就能背单词，不需要注册、不需要装 App、手机能用、断网能用（PWA）。
2. 每个单词都有一张**能被搜索引擎和 AI 搜索读到**的静态词条页，内容深到同行比不了。
3. 以键盘为核心做练习：打字默写、听写、例句填空，顺带练出肌肉记忆。
4. 学习进度存在浏览器本地（localStorage），下次打开接着学，支持导出备份。

### 非目标（本期不做）
- 不做账号体系、不做云同步、不做排行榜、不做社交。
- 不做 OCR 拍照查词、不做好友 PK、不做付费内容。
- 不做 AI 对话答疑（无后端，不引入模型调用）。
- 不做英文版（本站面向国内学习者；`llms.txt` 与结构化数据仍保持英文可读）。

## 五、词条页规范（SEO / GEO 主力）

每个词条页从上到下：

1. **H1 = 单词**，紧随音标（US / UK，来自 ECDICT）与发音按钮。
2. **首段给结论**（GEO 要求）：一行「级别 + 中文核心释义 + 词频/柯林斯星级」，让 AI 抓第一段就能引用。
3. **中文释义**：按词性分行（来自 ECDICT `translation`）。
4. **正文八节**（来自词典正文，解析后渲染）：
   - 分析词义 / 列举例句（每条英文 + 中文，各自带朗读按钮，并带「用这条例句练打字」入口）/ 词根分析 / 词缀分析 / 发展历史和文化背景 / 单词变形 / 记忆辅助 / 小故事
   - 解析器需兼容 `### 分析词义` 与 `分析词义：` 两种标题写法；无小标题的正文整段回落到「词义详解」。
5. **开始背这个词**按钮 → 跳 `/learn?w=<word>`。
6. **相关词**：同词根的词 / 同级别高频邻词（各 6–10 个）。
7. **底部来源署名** + 可见的「最后更新」`<time>`。
8. **结构化数据**：`DefinedTerm` + `BreadcrumbList` + `WebPage`；`datePublished` 固定为上线日，`dateModified` 跟随内容变动。

其他约定：
- `canonical` 不带 `.html`；分享图统一用 `og/word.jpg`（按词书分 6 张，不逐词生成）。
- slug 规则：小写 → 非 `[a-z0-9]` 字符转 `-` → 折叠重复 `-` → 去首尾 `-`；空或冲突时追加 `-2`、`-3`。展示仍用原始词形。
- 词条页**不写进 Git**（`.gitignore` 忽略 `/w/`、`/list/`、`/roots/`、`/guide/` 等生成物中体积大的部分），上线脚本先生成再上传。

## 六、学习器设计（`/learn`）

单页应用，原生 JS + CSS，无框架、无外部依赖。

### 6.1 流程
选词书 → 选模式 → 设定每日目标（默认 20 词/天）→ 练习 → 结算（正确率、本次掌握、连续天数）。

### 6.2 五种模式
| 模式 | 玩法 | 键盘 |
| --- | --- | --- |
| 卡牌速览 | 正面单词+音标+发音，翻面看释义，自评「认识 / 模糊 / 不认识」 | 空格发音，← → 切换，1/2/3 自评 |
| 打字默写 | 看中文释义（可开音标提示）敲英文，逐字符比对 | 直接输入，回车提交 |
| 听写辨词 | 只播放发音，敲出单词（可重放） | 空格重放，回车提交 |
| 例句填空 | 显示挖空例句，填入目标词（可开首字母提示） | 回车提交 |
| 选择题 | 英→中 或 中→英 四选一，干扰项取自同词书 | 1–4 选项，回车下一个 |

- 答错一律给出正确拼写并要求重打一遍（打字类），避免"看了一眼就过"。
- 每组默认 10 词，可调 5/10/20/50。

### 6.3 本地记忆（SRS）
- 每个词记一条进度：`{ box: 0-6, ease, due, seen, right, wrong, last }`。
- 简化 SM-2：答对升一盒并拉长间隔（1→2→4→7→15→30→60 天），答错回落并按 `ease` 调整；`due` 到期才进复习队列。
- 存储：`localStorage` 键 `v4u.progress.v1`（单词 → 进度）+ `v4u.meta.v1`（词书、目标、连续天数、每日统计）。
- 生词本：`v4u.star.v1`，收藏的词单独成组练习。
- 词量变大后 localStorage 可能吃紧（7954 词 ≈ 每词 80 字节 ≈ 650KB），可接受；超限时降级为只存练过的词。

### 6.4 数据加载
- `data/books.json`：词书元信息（名称、词数、分片文件名）。
- `data/words/<book>.<n>.json`：每片 500 词的精简词条（word / slug / 音标 / 中文释义 / 例句数组 / 变形 / 频率），学习器按需 `fetch`，由 Service Worker 缓存离线可用。
- 首屏只加载 `books.json` 与当前词书第 1 片，其余滚动或翻页时再取。

### 6.5 导出与备份
- 导出 Anki（Tab 分隔 txt）、CSV、打印版（`window.print()`，打印样式隐藏交互元素）。
- 导出 / 导入学习进度 JSON（换设备手动迁移）。
- 导出范围：当前词书 / 生词本 / 已掌握 / 未掌握。

### 6.6 发音
1. 默认走**真人发音**（`https://dict.youdao.com/dictvoice?audio=<word>&type=2`，美音；`type=1` 英音）。
2. 加载失败或离线时自动回落**浏览器内置语音** `speechSynthesis`（英文 voice，rate 0.9）。
3. 例句朗读统一用浏览器语音（避免逐句拼接口）。
4. 设置项可切换「只用浏览器语音」/「只用真人发音」。

### 6.7 无障碍与移动端
- 全部操作有可点按钮，键盘只是加速；`aria-live` 播报判题结果；对比度达 WCAG AA。
- 移动端输入框固定在视口内，不被软键盘顶飞；按钮 ≥ 44px。

## 九、部署与工程约定

- `wrangler.jsonc`：`name` = `vocab4u-suilang`，`assets.directory` = `.`，`html_handling: auto-trailing-slash`，`not_found_handling: 404-page`，`routes` 里 `vocab4u.suilang.net` 为 `custom_domain`。
- `scripts/重新上线.command`：先跑 `build/取数据.py`（缺数据时）与 `build/gen.py`，再 `npx wrangler@latest deploy`。目录可随意搬家（`cd "$(dirname "$0")/.."`）。
- `scripts/本地预览.command`：`python3 build/gen.py && python3 -m http.server 8848`。
- `scripts/提交给百度.command` / `提交给必应.command`：照抄现有站点，token 存 `scripts/.百度推送token.txt`（gitignore）。
- `.assetsignore` 排除 `.git`、`build`、`docs`、`scripts`、`README.md`、`*.command`、`wrangler.jsonc`（**不要写 `*.txt`**）。
- `_headers`：静态资源长缓存 + `?v=N` 版本号；CSP 放行 `https://suilang.net`（赞赏码）、`https://hm.baidu.com`、`https://dict.youdao.com`（发音音频，`media-src`）、`https://static.cloudflareinsights.com`。
- `_redirects`：开头写「不要写 `/xxx → /xxx.html`」警告注释；别名 `/book/<slug>` → `/list/<slug>`。
- 配置集中在 `assets/config.js`（域名 / 站名 / 统计 / 验证码 / 词书清单 / 页脚），生成脚本直接读取，不维护第二份。
- Git：只提交源代码、配置、合成数据（`data/` 里的成品）、生成器、文档；`/w/`、`/list/`、`/roots/`、`/guide/`、`build/_raw/` 忽略。推送走本机代理 `git -c http.proxy=http://127.0.0.1:7890 push`。

## 十二、决策记录

- **全部 7954 词都建词条页**：词条页是唯一能自己长流量、被 AI 引用的入口，成本只是「生成物不入库」。
- **五种模式一次做全**：模式共用同一套词数据与判题内核，后补的成本高于一次做对。
- **进度只存本地**：用户明确要求；顺带免去账号、隐私与合规负担，也符合站点群「不上传用户内容」的一贯做法。
- **发音双通道**：真人发音保证音质，浏览器语音保证离线可用，二者自动回落。
- **词书累计制 + 新增开关**：符合主流背单词软件的心智，也照顾「只补新增」的效率党。
